Privacy Policy — Leonida Replay

Last updated: November 16, 2026

Leonida Replay Poster is a personal, single-operator publishing tool used only by its owner (Eris Dothard) to upload short video clips to the owner's own TikTok, YouTube and Instagram accounts. It has no other users and offers no sign-in to the public.

YouTube API Services

This application uses YouTube API Services. By using it, the owner agrees to the YouTube Terms of Service. This application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google's own handling of data is described in the Google Privacy Policy.

What data is accessed

The application requests a single YouTube scope, https://www.googleapis.com/auth/youtube.upload, used only to upload the owner's own videos to the owner's own channel (the YouTube Data API videos.insert method). It does not read, list, analyze, or modify any other user's YouTube data, and requests no other scope.

What data is stored

The application stores only the owner's own OAuth token, in a permission-restricted file on the owner's own computer. No end-user data is collected, because there are no end users other than the owner. No data obtained through YouTube API Services is shared with, sold to, or transferred to any third party.

Revoking access and deleting data

The owner can revoke this application's access at any time at Google Account → Third-party apps & services. Revoking access invalidates the stored token; the owner can also delete the local token file to remove all stored credentials.

Content and removal

Clips credit and link the original streamer. To request removal of a clip, contact the account owner through the platform where it was posted.
